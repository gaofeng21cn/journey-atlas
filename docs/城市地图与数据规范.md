# 多尺度地图规范

地图能力以通用城市目录 `data/city-catalog.json` 定义层级、坐标系、边界资源名、来源和下载地址。城市目录是能力清单，不是访问记录；访问状态只能来自配置的数据源。

城市行政边界、道路与河流属于显示底图。它们不能核定到访、交通方式或路线。地点/行程/移动事实通过编号和时间关系进入地图，照片或 GPS 作为来源证据，不因底图覆盖而自动转换成景点。

## 城市资源

对城市 `city-id`，使用 `node scripts/fetch-city-geography.mjs city-id` 按目录配置下载公开边界和背景；资源遵循各上游许可证并保存在本地。缺少边界且用户数据中包含该城市地点时，构建会提示下载命令。缺少背景时仍可显示边界、地点和路线。

项目默认公开包不捆绑城市细节几何或 OpenStreetMap 道路切片。OSM 数据遵循 ODbL，地图展示须包含 “© OpenStreetMap contributors”；OpenFreeMap 的矢量底图还须包含 “OpenMapTiles · Data from OpenStreetMap”。日本国土地理院数据依其 PDL 1.0 标示来源。

## 区域来源

全国及省级边界由 `data/region-catalog.json` 指定，分母、标注和分享范围属于展示配置，不是访问事实。Natural Earth 边界使用 Public Domain；第三方资源的署名和再分发条件见根目录 `NOTICE.md`。

## 轨迹表达

城市移动记录必须使用稳定地点编号、行程编号、日期、段序和证据字段。可视化可展示有依据的估算；显示几何不代表历史实际路径。外部接续须连接有名边缘节点，只有服务城市或用户来源明确的城市名才能归一身份。
