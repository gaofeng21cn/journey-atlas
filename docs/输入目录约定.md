# 输入目录约定

`inputs/` 保存本地来源配置和待合并补丁，`data/source/` 保存通用源表，`private/evidence/` 保存稳定核定证据，`private/runtime/` 保存可重建中间产物。这些目录均被 Git 忽略。

一次导入以版本化 JSON bundle 提交，字段由 `scripts/schema.mjs` 定义。`npm run import:data -- --input <bundle.json>` 会检查未知字段、重复编号和已存在记录冲突；日常事实修订使用统一 `npm run update` 入口，先预览再应用。

原始照片、定位、机票和邮件附件留在使用者自己的原件库。源表记录证据引用和核定依据，不复制原件到代码仓库。公共配置和虚构示例放在 `data/*.example.json` 和 `examples/`。

已应用的补丁不再作为后续构建输入。需要长期回溯时归入用户自己的历史备份，不将旧快照自动加载回来。
